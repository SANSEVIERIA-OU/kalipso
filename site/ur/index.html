کیمرے کی طرف دیکھیں۔ Kalipso یاد رکھتا ہے آپ کی جگہ۔

ڈیسک ٹاپ کے لیے ٹیلی پرامپٹر۔ ویب کیم کے پاس چھوٹا مطالعہ دریچہ رکھ کر بولیں: Kalipso کمپیوٹر پر رہنے والی گفتار شناخت سے آپ کی آواز کی پیروی کرتا ہے، یکساں رفتار سے اسکرول کرتا ہے، یا پیڈل کا انتظار کرتا ہے۔

  3. دستی طور پر آگے بڑھیں

حقیقی استعمال میں

کیمرے کے عین نیچے، کسی بھی ایپ کے اوپر۔

کال، ریکارڈنگ یا پیشکش میں: Linux، Windows اور macOS پر مطالعہ دریچہ وہیں رہتا ہے جہاں آپ کی نگاہ ہونی چاہیے۔

وضاحت کے لیے بنائے گئے ڈیسک ٹاپ اور ایپ کے مناظر۔ ان میں Kalipso کی ونڈوز موجودہ نسخے کی حقیقی تصاویر ہیں۔

ڈیزائن ہی میں رازداری

آپ کے الفاظ آپ کے کمپیوٹر پر رہتے ہیں۔

  • نہ اکاؤنٹ، نہ کلاؤڈ۔ تقریر کے متون کمپیوٹر کے فولڈر میں سادہ ٹیکسٹ فائلیں ہیں۔
  • گفتار کی شناخت مقامی طور پر چلتی ہے۔ آڈیو کبھی کمپیوٹر سے باہر نہیں جاتا اور کچھ ریکارڈ نہیں ہوتا۔
  • فون ریموٹ کبھی تقریر کا متن نہیں دیکھتا۔ یہ صرف آپ کے اپنے نیٹ ورک سے شروع، توقف اور قدم بڑھانے جیسے حکم بھیجتا ہے۔

مزید خصوصیات

  • مقرر کے نوٹس اور دستاویزات

    PowerPoint اور Impress سے ہر سلائیڈ کا ایک حصہ بنا کر نوٹس، یا Word، Writer اور Markdown دستاویزات درآمد کریں۔

  • Impress کی براہ راست پیروی

    LibreOffice Impress سے پیش کریں، مطالعہ دریچہ اسکرین کی سلائیڈ کے نوٹس پر پہنچ جاتا ہے۔ Linux، Windows اور macOS پر۔

  • شیشے کے لیے آئینہ عکس

    متن افقی یا عمودی الٹیں بیم اسپلٹر ٹیلی پرامپٹر کے لیے۔ کنٹرول پڑھنے کے قابل رہتے ہیں۔

  • آسان مطالعہ

    A− اور A+ سے متن بڑا یا چھوٹا کریں، کوئی بھی موجود فونٹ، بشمول ڈسلیکسیا کے لیے بنے فونٹ، کشادہ سطری فاصلہ اور کناروں پر مدھم ہوتی سطریں۔

  • جہاں پڑھیں وہیں لکھیں

    ایک ونڈو: بڑی ہو تو مطالعہ دریچے میں ہی لکھیں، موٹے، ترچھے متن، براہ راست جانے والے حصوں اور [مسکرائیں] جیسے [اشاروں] کے بٹن کے ساتھ، جو کبھی پڑھے نہیں جاتے۔ کیمرے کے نیچے صرف مطالعہ دریچہ دکھتا ہے۔

  • کیسا رہا

    آواز والی نشست کے بعد: رفتار، طویل وقفے اور ہر حصے کا وقت، چاہیں تو رپورٹ محفوظ کریں۔

انسٹال کریں

Kalipso 3.1 حاصل کریں۔

Linux، Windows اور macOS کے مفت پیکج اجرا کے صفحے پر۔ ابھی ان پر ڈیجیٹل دستخط نہیں، اس لیے نظام پہلی بار تصدیق مانگتا ہے؛ SHA256SUMS وہاں ہر ڈاؤن لوڈ جانچا جا سکتا ہے۔

Linux ایپ

Arch اور EndeavourOS · Debian 13، Ubuntu 24.04 یا جدید تر · Fedora

مکمل ایپ: ایک ونڈو میں لکھنا اور پڑھنا، متون کی لائبریری، درآمد، منتقل اور منعکس ہونے والا مطالعہ دریچہ، فون ریموٹ اور آواز کی پیروی۔ ہر پیکج میں Plasma وجٹ، GNOME توسیع اور KWin اسکرپٹ بھی ہے۔

Arch Linux اور EndeavourOS، چلانے کے لیے تیار (kalipso اسے آپ کے کمپیوٹر پر بناتا ہے):

yay -S kalipso-bin

Debian اور Ubuntu، اس فولڈر میں جہاں آپ نے محفوظ کیا ہے .deb اجرا کے صفحے سے:

sudo apt install ./kalipso_*_amd64.deb

Fedora، اس فولڈر میں جہاں آپ نے محفوظ کیا ہے .rpm اجرا کے صفحے سے:

sudo dnf install ./kalipso-*.x86_64.rpm
دیگر تقسیمیں: مصدر سے بنائیں

KDE Plasma

Plasma 6 وجٹ

ڈیسک ٹاپ یا پینل پر مطالعہ دریچہ، ایپ میں لکھے آپ کے متون کے ساتھ۔ ایپ کے ہر Linux پیکج میں شامل ہے؛ ایپ کے بغیر شامل کریں .plasmoid اجرا کے صفحے سے۔ آواز کی پیروی کے لیے Kalipso معاون چاہیے۔

KDE ترتیب کی رہنما کتاب

GNOME

GNOME Shell 48 اور 51 کی توسیع

اوپری پٹی سے مطالعہ دریچہ، ایپ میں لکھے آپ کے متون کے ساتھ۔ ایپ کے ہر Linux پیکج میں شامل ہے: لاگ آؤٹ کر کے دوبارہ داخل ہوں، پھر Kalipso کی ترتیبات میں چالو کریں۔ ایپ کے بغیر اس کا یہ پیکج انسٹال کریں .zip اجرا کے صفحے سے۔ یہ آزمودہ Shell 48 اور 51 کی معاونت ظاہر کرتا ہے۔

GNOME ترتیب کی رہنما کتاب

macOS

Apple Silicon · macOS 14.4 یا بعد کا · تجرباتی

ایپ اس شکل میں .dmg: کھولیں اور Kalipso کو Applications میں کھینچیں۔ پہلی بار منتخب کریں پھر بھی کھولیں نظام کی ترتیبات ← رازداری اور سلامتی میں۔ آلے پر نظام کی گفتار سہولت کے لیے macOS 26 چاہیے۔

macOS کے لیے ڈاؤن لوڈ

Windows

Windows 10 یا 11، x64 · تجرباتی

ایپ اس شکل میں .msi انسٹالر یا قابل حمل .zip۔ اگر SmartScreen روکے تو منتخب کریں مزید معلومات، پھر پھر بھی چلائیں۔ آواز کی پیروی Windows میں انسٹال گفتار شناخت کنندگان استعمال کرتی ہے۔

Windows کے لیے ڈاؤن لوڈ

استعمال سے پہلے۔

کیا یہ میری کال یا ریکارڈنگ ایپ کے ساتھ کام کرتا ہے؟

Kalipso پڑھنے کی الگ ونڈو ہے؛ کسی مخصوص میٹنگ ایپ میں شامل کرنے کی ضرورت نہیں۔ ونڈو کی جگہ اور کیپچر کا رویہ ڈیسک ٹاپ کے مطابق بدلتا ہے۔ بھروسا کرنے سے پہلے اپنا اصل کال یا ریکارڈنگ انتظام آزمائیں۔

اسکرین بانٹنے پر کیا دوسرے اسے دیکھیں گے؟

Windows پر ایپ نظام سے مطالعہ دریچے کو اسکرین اشتراک اور ریکارڈنگ سے خارج رکھنے کو کہتی ہے۔ KDE Plasma 6.6 یا بعد کے نسخے پر کیمرے کے نیچے ہونے پر ونڈو خارج رہتی ہے۔ macOS ایپ کو ایسا کرنے کا معتبر طریقہ نہیں دیتا، اس لیے وہاں ایک ونڈو بانٹیں۔ ہر صورت پیشکش سے پہلے کسی دوسرے شریک کا منظر یا ریکارڈ کردہ ویڈیو دیکھیں۔

کیا یہ PowerPoint یا Impress کے نوٹس پڑھ سکتا ہے؟

جی ہاں۔ الگ ایپ مقرر کے نوٹس درآمد کرتی ہے ان فائلوں سے: .pptx اور .odp فائلیں، ہر سلائیڈ کا ایک حصہ۔ پیش کرتے وقت LibreOffice Impress سلائیڈ شو کی پیروی کر کے اسکرین کی سلائیڈ کے نوٹس پر بھی جا سکتی ہے۔

کن زبانوں کی پیروی کر سکتا ہے؟

ڈاؤن لوڈ فہرست میں انگریزی، جرمن، ہسپانوی، جاپانی اور چینی کے Moonshine ماڈل، اور ان کے ساتھ اطالوی کے Vosk ماڈل ہیں۔ شناخت کا معیار زبان اور ماڈل کے مطابق بدلتا ہے۔ دستی اور یکساں رفتار مطالعہ ہر زبان میں چلتا ہے۔ انٹرفیس ۳۹ زبانوں میں دستیاب ہے۔

کیا تقریر کا متن خود محفوظ ہوتا ہے؟

جی ہاں۔ الگ ایپ، Plasma وجٹ اور GNOME توسیع لکھتے وقت متن اور پڑھنے کی جگہ کمپیوٹر پر محفوظ کرتے ہیں۔ کچھ اپ لوڈ نہیں ہوتا۔ صرف یہ براؤزر نمونہ دوبارہ لوڈ کرنے پر ابتدائی حالت میں آتا ہے۔

کیا یہ اہم براہ راست پیشکش کے لیے تیار ہے؟

Kalipso 2.0 پہلی عوامی اجرا ہے۔ شناخت اب بھی آپ کی جگہ کھو سکتی ہے اور حقیقی کمپیوٹر اور مائیکروفون پر جانچ محدود ہے۔ نوٹس کی نقل رکھیں، دستی کنٹرول سیکھیں اور پہلے اپنے آلات پر مشق کریں۔
