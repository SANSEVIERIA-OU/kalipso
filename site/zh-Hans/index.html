以隐私为设计基础

您的话语留在您的电脑上。

  • 无需账号，不用云服务。 讲稿以纯文本文件保存在电脑上的文件夹中。
  • 语音识别在本地运行。 音频从不离开您的电脑，也不会被录制。
  • 手机遥控从不接收讲稿。 它只通过您自己的网络发送开始、暂停和逐步推进等命令。

还有哪些功能

为您的演示方式而设计。

  • 演讲者备注和文档

    从 PowerPoint 和 Impress 导入备注，每张幻灯片对应一章；也可导入 Word、Writer 和 Markdown 文档。

  • 实时跟随 Impress

    使用 LibreOffice Impress 演示时，阅读窗会跳转到屏幕上当前幻灯片的备注。支持 Linux、Windows 和 macOS。

  • 为玻璃设置镜像

    水平或垂直翻转文字，用于 分光玻璃 提词器。控件仍然正常可读。

  • 更轻松地阅读

    使用 A− 和 A+ 调整文字大小，选用任何已安装字体（包括为阅读障碍设计的字体），还可使用宽行距和边缘渐隐的文字行。

  • 在阅读的地方撰写

    一个窗口：展开时直接在阅读窗内撰写，提供粗体、斜体、可跳转章节，以及 [微笑] 等不会被朗读的[提示]按钮。缩小到摄像头下方时，只显示阅读窗。

  • 回顾表现

    语音会话结束后：查看语速、长停顿和各章节耗时，需要时可保存为报告。

安装

获取 Kalipso 3.0。

Linux、Windows 和 macOS 的免费安装包位于 发布页面。安装包尚未签名，因此首次运行时系统会要求确认； SHA256SUMS 可在那里校验每次下载。

Linux 应用

Arch 和 EndeavourOS · Debian 13、Ubuntu 24.04 或更新版本 · Fedora

完整应用：在一个窗口中撰写和阅读，提供讲稿库、导入、可移动和镜像的阅读窗、手机遥控和语音跟随。每个安装包还包含 Plasma 小组件、GNOME 扩展和 KWin 脚本。

Arch Linux 和 EndeavourOS，即装即用（kalipso 会在您的电脑上构建）：

yay -S kalipso-bin

Debian 和 Ubuntu，在保存了 .deb 的文件夹中，文件来自发布页面：

sudo apt install ./kalipso_*_amd64.deb

Fedora，在保存了 .rpm 的文件夹中，文件来自发布页面：

sudo dnf install ./kalipso-*.x86_64.rpm
其他发行版：从源代码构建

使用之前。

能与我的通话或录制应用配合使用吗？

Kalipso 是独立的阅读窗口，无需嵌入特定会议应用。窗口位置和捕获行为因桌面环境而异。在依赖它之前，请用实际的通话或录制设置测试。

共享屏幕时，其他人会看到它吗？

在 Windows 上，应用会请求系统在屏幕共享和录制中排除阅读窗。在 KDE Plasma 6.6 或更新版本上，窗口处于摄像头下方时会被排除。macOS 没有可靠的应用接口实现这一点，因此请在该系统上共享单个窗口。无论哪种情况，演示前都请从另一位参与者的视角或录制视频中确认效果。

能读取 PowerPoint 或 Impress 备注吗？

可以。独立应用可以导入以下文件中的演讲者备注： .pptx 和 .odp 文件，每张幻灯片对应一章。还可以在您演示时跟随 LibreOffice Impress 放映，移动到当前幻灯片的备注。

可以跟随哪些语言？

下载目录提供英语、德语、西班牙语、日语和中文的 Moonshine 模型，以及这些语言和意大利语的 Vosk 模型。识别质量因语言和模型而异。手动和匀速阅读支持任何语言。界面提供 39 种语言。

讲稿会自动保存吗？

会。独立应用、Plasma 小组件和 GNOME 扩展会在您输入时将讲稿和阅读位置保存在电脑上，不上传任何内容。只有此浏览器演示会在重新加载时重置。

可以用于重要的现场演示了吗？

Kalipso 2.0 是第一个公开版本。识别仍可能丢失阅读位置，在真实电脑和麦克风上的测试仍然有限。请保留备注副本、熟悉手动控件，并先在自己的设备上排练。
